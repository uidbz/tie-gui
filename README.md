### Simple image viewer with gallery feature

It loads thumbnails with 8 Go routines, so it is pretty fast.

Hotkeys/controls:  
In gallery mode: 
Q: Quit
Esq: Quit 

In single picture mode: 
Esq: Go back to gallery 
Right: Next picture 
Left: Previous picture 
Scroll down: Zoom in 
Scroll up: Zoom out 
Drag image to reposition 
X: Fit to window 
F: Fullscreen (fails on wayland)
